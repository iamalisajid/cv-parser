# CV Parser frontend

React and Vite dashboard for the CV Parser API. From this directory, run `npm ci` and `npm run dev`. Set `VITE_GOOGLE_CLIENT_ID` in `frontend/.env` to your Google OAuth web client ID. Optionally set `VITE_ALLOWED_EMAIL_DOMAIN` to display your configured sign-in restriction. The Vite dev server proxies `/api` to `http://localhost:8000`.
